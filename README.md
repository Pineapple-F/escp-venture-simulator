# ESCP 创投模拟器 2.0

2.0 代码位于 `market-simulator/`，包含投资人端与企业端，并共用历史企业资料。

- 投资人端：企业筛选、模拟投资、成本记账和账户资金图。
- 企业端：企业与人员资料、融资历史可视化、机构池、融资方案、按周反馈、条款确认与模拟交割。
- 企业未来预测：读取所选企业截至资料截止日的全部有效历史，运行最佳金融事件 diffusion，按月份展示未来12个月路径；模型结果、用户行动计划和后续事实核对分别记录。
- 融资情景路径：将已保存的融资方案和已选机构追加到企业完整历史路径，重新运行同一模型，展示更新后的未来一年事件及与原路径的变化。
- 企业自建路径：企业无需存在于ESCP中，只需选择日期、事件大类和具体事件；网站自动标准化后预测未来一年，并检索同企业年龄下路径相似的历史企业及其随后一年实际记录。
- 投资人未来机会池：使用同版本物化预测，按事件与3/6/12个月窗口筛选企业，支持关注、跟进和企业详情核验；预测不会自动触发投资或拒绝。
- 历史事实和模拟参数分别记录，不将模拟报价、估值或收益表述为真实市场结果。

## 运行 2.0

仓库已包含网站运行需要的匿名数据快照。克隆后在项目根目录执行：

```sh
./start.sh
```

脚本会首次创建 Python 虚拟环境、安装依赖并启动网站。打开 http://127.0.0.1:8790 。需要 Python 3.10 或更高版本。

仓库同时包含事件预测的最佳权重、必要推理代码、匿名历史输入、金融语义缓存和投资人预测目录。FinBERT2-large 权重约 1.3GB，超过 GitHub 普通文件限制，会在首次使用预测功能时按固定版本自动下载。离线部署方法见 `model-runtime/README.md`。

仓库包含 `processed/cleaned/` 匿名清洗数据和 `market-simulator/runtime/universe-v3.json` 运行快照；不包含本机账户数据库、虚拟环境及未匿名原始数据。账户记录会在首次运行后写入本机 `market-simulator/runtime/saves.sqlite3`。

Cloudflare 部署配置面向 `https://venturesimulator.actscal.org/`：现有前端由 Workers Static Assets 托管，`/api/*` 转发到 Python Container。线上账户存档保存在 Durable Object SQLite 中，容器重建不会依赖本地存档文件恢复；本地运行仍使用 SQLite 文件。当前不需要另外部署 MySQL。

根目录 Dockerfile 打包网站、匿名数据与固定版本预测模型。推送 `main` 后由 GitHub Actions 自动测试、构建和发布；部署成功需以 Actions 及线上验收为准。账号开通、权限、价格和操作步骤见 [Cloudflare 部署说明](docs/cloudflare-deployment.md)。
