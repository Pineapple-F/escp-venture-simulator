# ESCP 创投模拟器 2.0

2.0 代码位于 `market-simulator/`，包含投资人端与企业端，并共用历史企业资料。

- 投资人端：企业筛选、模拟投资、成本记账和账户资金图。
- 企业端：企业与人员资料、融资历史可视化、机构池、融资方案、按周反馈、条款确认与模拟交割。
- 历史事实和模拟参数分别记录，不将模拟报价、估值或收益表述为真实市场结果。

## 运行 2.0

参见 `market-simulator/README.md`。安装该目录依赖后运行：

```sh
cd market-simulator
.venv/bin/python server.py
```

打开 http://127.0.0.1:8790 。完整运行需要项目私有清洗数据或受信任的本地运行快照；仓库不上传原始数据、清洗数据、账户数据库和本地环境。

`demo/`、根目录 Dockerfile 和 Cloudflare 工作流仍为旧版入口，本分支不会自动替换线上旧站。
