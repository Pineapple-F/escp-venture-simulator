# 网站预测：季度截点微调

在已提交的网站预测模型上，使用 2014–2021 年每季度末的预测截点继续训练。输入仍为截点之前最多64条受支持事件，目标为之后365天内五类事件的首次发生，包含空窗口。2022-12-31 验证集与 2023-12-31 留出集的字段数值与既有实验逐项一致；同一企业可在不同训练截点重复出现。训练集最新目标日不晚于 2022-12-31，未跨过验证预测起点。原模型和预测目录均保留。

在读取新实验验证结果前，确定选择规则：以五类事件验证 F1 宏平均为主要指标，平均精度宏平均和各类 F1 为辅助；只有综合改善且没有明显单类退步（F1 下降超过 0.03）时才更新。每个候选的阈值和时间调整只根据同一验证集拟合；最终留出集仅在确定单一模型后报告，不能用于选择候选或阈值。时间误差仍在全部真实正例上计算。

训练集 152,441 个窗口（10,381 家企业），验证 11,796、留出 13,636；训练正例数按五类依次为 11,632、10,400、5,106、1,281、635。训练来源的企业和验证企业可重合，结果主要评估固定企业池的时间外推，不代表新企业泛化能力。

## 结果

从上一版最佳权重初始化，使用 FP32 和 Adam（学习率 0.0002）训练三个完整周期，每周期保存检查点。根据上面的预设验证规则选择第二周期（4,762 次更新）；训练中候选交互层及其输入投影均有有限的非零梯度和参数变化。
