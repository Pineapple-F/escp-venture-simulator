# SGL 投资方推荐

2026-11-05 已接入。入口只展示搜索栏及投资方结果列表。点击结果后，右侧展开该投资方的真实资料和交互式知识图谱；确认区位于右侧下方，点击“确认投资方”后才进入工作台。输入任意名称不能创建身份，预览不会更改当前账户。

预览图谱与企业端保持一致的节点配色、节点详情和来源展示，支持拖动、缩放与适应视图。列表、右侧预览和进入工作台使用轻量过渡，尊重系统减少动态效果设置；手机采用上下排列。

进入后左侧展示“我的知识图谱”，右侧直接展示 10 家推荐企业；不显示推荐标题、模型标签、模型说明、日期与计算耗时，无需再次选择投资方或点击推荐按钮。身份保存到账户中，刷新后继续使用；已有未绑定身份的账户会先补选身份，并保留原有存档。点击“更换投资方”可重新搜索并切换，推荐和图谱会一起更新。切换身份保留当前模拟资金与操作记录，不把它们改成真实投资历史。

“我的知识图谱”从当前投资方在数据库中的历史融资参与记录构建，按投资方 → 融资事件 → 企业显示，最近最多 12 条事件。未参与 SGL 训练的投资方同样展示真实图谱。历史被投企业即使不在当前网站的企业范围内，也保留为图谱节点；只对网站可查看的企业提供详情入口。缺少披露日的记录会注明以事件日代替。

## 推荐规则

- 投资方按 `investor_key_anon` 精确匹配；企业按 `company_id_anon` 精确匹配。观察账户的名称、游客点击和浏览记录不作为模型投资方。
- 已训练投资方：使用原 SGL 最终向量的点积排序，不混入热门分数。
- 未出现在训练集中的真实投资方：按企业历史上不同投资方的数量降序推荐；重复轮次不重复计数。过滤各自已投企业后，结果可能不同。
- 两种方法都排除已知历史被投企业，返回 10 家不重复且能在当前网站查看的企业。候选不足 10 家时返回实际数量，不以已投企业凑数。
- 模型缺失、损坏或 ID 不匹配时返回明确错误，不把模型故障伪装成热门推荐。
- 推荐是只读操作，不创建模拟投资、不改账户存档、不向知识图谱添加投资边。

当前网站有 13,687 个可选投资方，其中 12,287 个匹配 SGL，1,400 个走热门推荐。SGL 的 20,061 家训练企业中，10,563 家也在网站当前企业范围内；SGL 排序只使用这部分交集。

## 已采用的模型

| 项目 | 内容 |
|---|---|
| 实验 | `dual_split_20261026/static_random__SGL__s42` |
| 选择依据 | 验证集 NDCG@10 最优的第 140 轮；固定 seed 42 |
| 模型规模 | 13,027 个投资方，20,061 家企业，64 维，3 层传播 |

| 线上资产 | `market-simulator/recommendation-assets/sgl/embeddings.npz` 与 `manifest.json`，合计约 8.4 MiB |
| 完整已投关系 | 45,818 对，用于排除已投企业；线上另合并网站已披露历史 |
| 原始权重 SHA256 | `adcbb1ddfea1c4ef00a53a88ba320ce889eea520b3fed47a86a5a1b33376977f` |

从已训练权重导出最终图传播向量，没有重新训练。用原作者 SGL 编码器核对，图传播输出最大误差为 0，点积评分最大误差约 2.5e-6。导出的文件不包含优化器，也不包含推理时不需要的训练图。

**时间口径：**该实验为静态历史关系补全，模型训练历史最晚到 2026-04-03；网站企业资料及热门统计截止 2026-03-31。模型历史日期和已投资料核对日期保留在接口与本文档中，推荐栏不显示这些信息；不能把本功能当作严格截至 3 月 31 日的未来投资回测。验证/测试中已知的历史投资仅加入生产环境的排除列表，没有用于重新拟合模型。

## CPU 耗时

2026-11-05 本机实测，未启动 GPU 或重新训练：

| 测量范围 | 样本数 | 中位数 | P95 | 最大值 |
|---|---:|---:|---:|---:|
| SGL 排序 | 200 | 1.256 ms | 3.876 ms | 5.966 ms |
| 热门排序 | 200 | 0.431 ms | 0.857 ms | 1.495 ms |
| 8 路并发推荐计算 | 200 | 2.052 ms | 13.682 ms | 50.848 ms |
| 本地完整推荐 HTTP 请求，含身份、会话及 JSON | 80 | 16.905 ms | 31.830 ms | 38.597 ms |

测试服务器首次导入约 2.18 秒。每次 HTTP 测量前已绑定对应投资方，表中不含身份切换请求。推荐请求只进行 NumPy CPU 点积、过滤和排序，不运行训练、不运行图传播，也不调用事件预测模型。

以上是本地数据，不包含公网延迟与 Cloudflare 休眠容器唤醒。前端在 9.5 秒结束等待并提供重试；这不能保证休眠后的第一次请求一定成功。现有 Worker 的容器休眠设置保持为 10 分钟。

## 更新和部署

当前导出包已放入项目目录，直接运行网站即可使用。Dockerfile 原有的 `COPY market-simulator/` 会一起打包它；`npm run build` 会复制新增的推荐页面资源。GitHub Actions 已加入推荐单元测试及部署后的 Top10/耗时检查。推送 main 后沿现有流程自动部署，不需要单独购买推荐 GPU 服务。

以后拿到新的训练权重，只需重新导出这两个资产，保留同版 ID 映射和训练矩阵；不要混用不同清洗版本。导出依赖 PyTorch、SciPy、pandas，仅离线导出使用。示例从 Knowledge Graph 目录运行：

```powershell
python D:/Learn/Program/ESCP/escp-venture-simulator/scripts/export_sgl_recommender.py --checkpoint agent/artifacts/sgl_production_20261105/best.pt --dataset data/ESCPdata/dual_split_20261026/static_random --knowledge-root . --all-history data/ESCPdata/clean_origin_three_table_20261025/investment_edges.parquet
```

服务接口：

- `GET /api/recommendation-investors?q=关键词&page=1`：进入前即可搜索或浏览数据库中的投资方；多个关键词以空格分隔，支持名称或 ID。
- `GET /api/investor-preview?investor_id=ik_...`：只读预览投资方资料和历史关系，无需账户，不保存身份；行业、地区与阶段字段表示历史被投记录，不推测投资方注册地址或投资偏好。
- `POST /api/new`：投资方账户必须传入数据库中的 `investor_id`；企业工作台明确传入 `workspace: founder`。
- `POST /api/investor`：传入 `investor_id` 和当前 `revision`，为已有账户绑定或更换身份；保存时校验版本，避免覆盖并发操作。
- `GET /api/recommendations`：自动按已保存的当前投资方返回 Top10、方法、模型版本和计算耗时。
- `GET /api/investor-graph`：自动按已保存的当前投资方返回自己的图谱。

搜索接口允许在进入前读取；推荐、自己的图谱和投资方操作需要已绑定的新版账户。建立或切换身份时，缺失或伪造 ID 返回 400；账户未选择身份或试图用查询参数切换他人推荐返回 403；模型故障返回 503。企业端仍可独立进入，但不能绕过投资方身份要求。
